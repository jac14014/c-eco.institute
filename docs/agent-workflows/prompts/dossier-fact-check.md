# Verify a c-ECO document

## Inputs

Current complete document, its approved predecessor, the controlling c-ECO working document, the evidence register, and any author-approved changes. State which inputs are missing before drawing conclusions.

## Prompt

Audit the attached c-ECO document for factual accuracy, evidence, internal consistency and institutional status. Read the complete file. Do not infer that a planned Lab, partnership, funding award, staff position, software feature or legal authorization already exists.

1. Extract each material, externally checkable assertion into a claim register. Include document section, exact short claim, source cited in the document, evidence needed and whether the claim affects a key conclusion.
2. Verify scientific, geographic, organizational and legal-status claims against original papers, institutional records or official sources as appropriate. Give a direct source link and date checked. Distinguish a fact about an external institution from a c-ECO partnership with it.
3. Compare the document with approved c-ECO decisions. Check 22 Labs versus GIH and Institute, the current deployment sequence, L0–L3 roles, GIH administration of the single SIL platform, Fellow entry and institutional project approval. Treat older cost models and proposed rosters as historical when a newer decision conflicts.
4. Mark each claim VERIFIED, DOCUMENTED PLAN, PLANNING ASSUMPTION, EVIDENCE GAP, CONFLICT or INCORRECT. A source that does not support the precise assertion is an evidence gap.
5. Identify unsupported causal leaps, inconsistent numbers, inaccurate citations, names or dates, and claims that turn a proposal into an accomplished fact.
6. Return a severity-ranked findings table with minimal wording changes, evidence links and an owner or next action for unresolved items. Preserve approved substance; propose changes to core conclusions separately for human review.

Do not alter the source document unless explicitly asked. Do not describe a completeness check as scientific validation or legal approval. For an Amazon or Tromsø dossier, apply this prompt separately to the final full HTML of that Lab.
