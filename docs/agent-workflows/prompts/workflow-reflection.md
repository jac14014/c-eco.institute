# Improve a repeated c-ECO workflow

## Prompt

Review the recent c-ECO dossier or research workflow. Inspect the actual prompts, output sections, corrections, evidence logs and approved templates before proposing a new reusable instruction.

Identify repeated friction: sections that require the same source check, recurring confusion about GIH versus Geneva Lab, inconsistent 19-domain labels, outdated Lab rosters, lost approvals, repeated formatting fixes, or research tasks that produce unsupported partner claims.

For each candidate, record at least two concrete examples, the cost of repetition, the risk of inconsistent results, and whether an existing instruction already covers it. Choose the smallest useful remedy: a change to a shared prompt, evidence-register field, checklist, document template or agent handoff. Recommend a dedicated agent only where a distinct continuing role is justified.

Return a short proposed change with its exact location and acceptance criterion. Do not silently change approved dossier content, agent permissions, account access or global configuration. If the evidence for repetition is weak, say so and create nothing.
